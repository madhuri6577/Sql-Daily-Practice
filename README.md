SQL Practice

This repository contains my daily SQL practice, covering concepts from basic to advanced SQL.

📚 Topics Covered

- SELECT and filtering
- DISTINCT
- WHERE
- ORDER BY
- LIMIT
- Aggregate Functions
- GROUP BY
- HAVING
- CASE WHEN
- JOINs
- Subqueries
- Correlated Subqueries
- Window Functions
- CTEs
- Advanced SQL Queries
- Real-world Data Analysis

📅 Practice Structure

The SQL practice is organized day by day:

- Day 1 – Day 8: SQL practice using the initial practice dataset
- Day 9 onwards: SQL practice using a large real-world e-commerce dataset

Each day contains the SQL queries and problems practiced on that day.

📊 Dataset

From Day 9 onwards, I use the Brazilian E-Commerce Public Dataset by Olist.

The dataset contains multiple related tables, including:

- Customers
- Orders
- Order Items
- Products
- Sellers
- Order Payments
- Order Reviews
- Geolocation
- Product Category Translation

Dataset source: "Brazilian E-Commerce Public Dataset by Olist" (https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

The raw dataset is not included in this repository because some CSV files exceed GitHub's file-size limit.
